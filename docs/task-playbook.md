# Gujarat Watch Company Task Assignment Playbook

Use these from the dashboard or Telegram.

## CEO Daily Tasks
/assign @CEO Review overnight orders, revenue, urgent issues, and set today's top 3 priorities against INR 1,111 daily revenue target.
/assign @CEO Review all department updates and assign blockers to correct agents with owner and deadline.

## Marketing Daily Tasks
/assign @Marketing Create tomorrow's Instagram content plan: 9 AM lifestyle post, 1 PM deal post, 6 PM premium post, 9 PM teaser. Include captions, CTA, hashtags, and CEO approval notes.
/assign @Marketing Review today's ad performance. Pause ROAS below 2:1, scale ROAS above 4:1 by 20%, and recommend tomorrow's budget allocation.
/assign @Marketing Plan 2 reels for tomorrow: one product showcase and one testimonial/educational reel with scene list, text overlays, CTA, and hashtags.

## Graphic Designer Daily Tasks
/assign @Graphic-Designer Create a 1080x1080 Instagram launch poster for a new watch collection. Include exact on-image text, layout, colors, font choices, CTA, and Canva steps.
/assign @Graphic-Designer Create a 5-slide Instagram carousel for new arrivals with slide-by-slide copy, layout, product placement, and brand styling.
/assign @Graphic-Designer Create a 1080x1920 story graphic for a flash sale with urgency, offer badge, CTA, and mobile-safe text placement.

## Sales Daily Tasks
/assign @Sales Prepare WhatsApp follow-up scripts for overnight inquiries, including price objection, warranty concern, and decision-delay responses.
/assign @Sales Review hot leads and recommend which leads should receive discount, urgency, testimonial, or lower-price alternative.
/assign @Sales Draft Instagram DM replies for product comments and first-time buyer offer GWCFIRST5.

## Support Daily Tasks
/assign @Support Review unresolved customer tickets and create response plan with priority, owner, and resolution deadline.
/assign @Support Draft response for customer complaint or return request while protecting satisfaction score above 4.5/5.

## Operations Daily Tasks
/assign @Operations Check inventory risk: items below 5 units, dead stock over 30 days, pending pre-orders, and dispatch blockers.
/assign @Operations Prepare daily dispatch and QC report with count, Shiprocket pickup status, defects, packaging issues, and return risk.

## Procurement Daily Tasks
/assign @Procurement Review reorder needs and recommend POs with vendor, quantity, MOQ, lead time, expected margin, and approval requirement.
/assign @Procurement Find 5 new watch designs/vendors aligned with minimalist, vintage, sports, or local artisan demand.

## Tech Daily Tasks
/assign @Tech Check website health: uptime, 500 errors, Razorpay flow, Shiprocket API, seller portal, admin panel, and backup status.
/assign @Tech Plan next feature implementation for wishlist, reviews, email notifications, or seller analytics with files affected and risks.

## Automation Daily Tasks
/assign @Automation-Engineer Verify cron jobs, Razorpay order creation, Shiprocket token cache, email notifications, and daily report automations.
/assign @Automation-Engineer Generate an automation improvement plan to reduce one manual workflow this week.

## Finance Daily Tasks
/assign @Finance Reconcile Razorpay sales, ad spend, shipping costs, commissions, vendor payments, and refunds for today.
/assign @Finance Calculate daily profit estimate and flag margin, cashflow, or CAC risks.

## Data Analyst Daily Tasks
/assign @Data-Analyst Analyze today's traffic, orders, conversion rate, revenue, AOV, top product, source split, and recommend one action per department.
/assign @Data-Analyst Compare this week's revenue against INR 7,777 target and forecast whether month target INR 33,333 is on track.
